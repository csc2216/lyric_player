# 歌詞播放器（Lyric Player）

本機用的歌詞翻譯播放網站：輸入歌名 → 自動找 YouTube 影片與 LRCLIB 同步歌詞 → 逐行翻成台灣繁體中文 → 存進歌曲庫（依歌手分類）。播放時點任一行歌詞就從那裡開始播，目前這行會亮起並自動捲動。

只在自己電腦上跑（localhost），不需要帳號或部署。開發規格與設計細節見 `CLAUDE.md`。

---

## 安裝

需要 Windows + WSL（Ubuntu）。以下指令都在 **WSL 終端機**裡執行。

1. **安裝 uv**（Python 套件與環境管理）

   ```bash
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```

   裝完重開終端機，`uv --version` 有版本號就好。

2. **安裝並登入 Claude Code**（翻譯用，走你的 Claude 訂閱額度）

   依 [Claude Code 官方說明](https://docs.claude.com/en/docs/claude-code) 安裝後，在終端機執行一次 `claude`，照指示登入。
   之後 `claude --version` 能執行就好。沒有訂閱、改用 API key 的話見下方「設定」。

3. **取得專案並安裝相依套件**

   ```bash
   cd ~/lyric_player        # 專案所在位置
   uv sync                  # 第一次會下載 Python 與套件
   cp .env.example .env     # 建立設定檔（預設值就能用）
   ```

4. **確認可以動**（可略過）

   ```bash
   uv run pytest                                  # 後端測試
   uv run python scripts/try_pipeline.py "IU - 밤편지"   # 實際搜尋 + 翻譯一次，不存檔
   ```

### 設定（`.env`）

| 變數 | 預設 | 說明 |
|---|---|---|
| `TRANSLATOR_BACKEND` | `claude_cli` | `claude_cli`：呼叫 `claude -p`，用訂閱額度；`api`：用 Anthropic API key |
| `CLAUDE_CLI_PATH` | `claude` | 伺服器找不到 `claude` 時填完整路徑（見常見問題） |
| `ANTHROPIC_API_KEY` | 空 | 只有 `TRANSLATOR_BACKEND=api` 需要 |
| `TRANSLATE_MODEL` | `claude-sonnet-5-5` | 翻譯用的模型 |
| `LIBRARY_DIR` | `./library` | 歌曲庫資料夾（JSON 檔，可自行備份） |
| `VIDEO_PREFERENCE` | `sync` | `sync`：選時長最接近的影片（時間軸最準）；`mv`：偏好 MV |

## 啟動

### Windows：一鍵啟動（平常用這個）

雙擊專案根目錄的 **`start-lyric-player.bat`**：

- 會在背景啟動伺服器，好了之後自動用預設瀏覽器開 <http://localhost:8765>
- 伺服器已經在跑時，只開瀏覽器，不會重複啟動
- 視窗會顯示「伺服器運行中」——**關閉這個視窗伺服器就會停止**

**建立桌面捷徑：**

1. 在 WSL 終端機進到專案資料夾執行 `explorer.exe .`（或在檔案總管網址列輸入 `\\wsl.localhost\Ubuntu\home\<你的帳號>\lyric_player`）
2. 在 `start-lyric-player.bat` 上按右鍵 →「顯示其他選項」→「傳送到」→「桌面（建立捷徑）」
3. （可選）捷徑按右鍵 → 內容：「變更圖示」換圖示；「執行」選「最小化」讓視窗縮在工作列

### WSL：開發用

```bash
./run.sh          # 有 --reload，改程式自動重載；瀏覽器開 http://localhost:8765
```

## 日常使用

### 畫面

- **左**：歌曲庫（依歌手分類，上方可過濾）。« 收合成細條、» 展開，或按 **B**。
- **中**：建立歌曲的輸入框、⚙ 設定、影片、歌曲資訊與功能按鈕。
- **右**：歌詞（原文＋翻譯），自己捲動。

視窗寬度小於 1000px 時改成上下排列。

### 建立一首歌

1. 在中間輸入框打 **`歌手 - 歌名`**（最準），或只打歌名，按「建立」。
2. 狀態列會顯示「搜尋中」→「翻譯中」（翻譯約 5–10 秒，有秒數計時）。
3. 找得很確定時會**自動建立**；不確定時右側會列出候選（歌手、歌名、時長、是否有同步歌詞、前 3 行預覽、配對到的影片與時長差），挑一個「用這個建立」。
   - 候選影片時長差標成橘色（> 3 秒）代表時間軸可能需要調整。
4. 同一首歌已經在歌曲庫的話會直接打開，不會重翻。

### 播放

- **點任一行歌詞**：從那行開始播。目前這行會亮起，歌詞自動捲動跟著走（設定可關，或按 **A**）。
- 自己捲動歌詞時，自動捲動暫停 3 秒；目前這行不在畫面上時右下角會出現「回到目前歌詞」，或按 **C**。
- **← / →** 跳到上一行 / 下一行。**Space** 播放 / 暫停。
- 「放大影片」讓影片佔滿中間＋右側，**Esc** 還原。

### 修正與管理

| 想做的事 | 怎麼做 |
|---|---|
| 歌詞整體太早 / 太晚亮 | **[ / ]** 調 ±0.1 秒、**Shift+[ / ]** 調 ±1 秒（停手 1 秒自動存）；或用「校準時間」（見常見問題） |
| 改某行翻譯 | 雙擊翻譯文字 → 修改 → **Enter** 存、**Esc** 取消 |
| 某行翻得不好 | 滑鼠移到那行，按右側 **↻** 單獨重翻 |
| 整首重翻 | 「全部重翻」（會覆蓋手動修改） |
| 影片不對 / 不能播 | 「換影片」從候選挑，或貼上任何 YouTube 網址。影片被禁止嵌入時會**自動換下一個候選** |
| 改歌手或歌名 | 「編輯資訊」。歌手名稱跟既有歌手相同時（括號內別名不算，例如 `IU (아이유)` = `IU`）會併入同一個歌手 |
| 沒有同步歌詞的歌 | 「打點同步」：跟著歌在每行開始唱時按 **Enter**（或 **S**），按錯按 **Backspace**，打完自動存 |
| 刪除 | 「刪除」（會再確認一次） |

### 設定（⚙）

自動捲動、排版（原文翻譯上下兩行 / 同一行）、主題（跟隨系統 / 淺色 / 深色）、點行時提早幾秒開始播。設定存在瀏覽器裡。

## 鍵盤快捷鍵

在輸入框或編輯翻譯時，快捷鍵不會作用（可以正常打字）。焦點在 YouTube 影片裡時，鍵盤由 YouTube 處理——點一下歌詞區就回來了。

| 鍵 | 動作 |
|---|---|
| Space | 播放 / 暫停 |
| ← / → | 上一行 / 下一行 |
| [ / ] | 歌詞 offset −/+ 0.1 秒（停手 1 秒自動存檔） |
| Shift+[ / Shift+] | 歌詞 offset −/+ 1 秒 |
| C | 把目前的歌詞行捲回畫面中央 |
| A | 開關自動捲動 |
| B | 收合 / 展開左側歌曲庫 |
| Shift+S | 進入 / 離開校準模式 |
| S | 校準中：第一下開始播、第二下記錄；打點中：記錄這一行 |
| Enter | 校準確認階段：確定；打點中：記錄這一行 |
| Backspace | 打點中：退回上一行重打 |
| Esc | 依序：還原放大的影片 → 取消打點 / 校準 → 關閉面板 |

## 常見問題

### YouTube 搜尋失敗／找不到影片（yt-dlp 壞掉）

YouTube 改版時 yt-dlp 偶爾會失效，錯誤訊息通常是「YouTube 搜尋失敗：…」。更新它：

```bash
cd ~/lyric_player
uv lock --upgrade-package yt-dlp && uv sync
```

然後關掉伺服器視窗重新啟動（`./run.sh` 的話按 Ctrl+C 再執行一次）。

### 時間軸不準（歌詞亮得太早或太晚）

先判斷是「整首都偏同樣的量」還是「越後面越偏」：

- **整首都偏一樣多**（最常見，影片前奏比較長或短）：
  1. 按「**校準時間**」（Shift+S）。目標預設是第二行，可以點別行改選。
  2. 按 **S**，影片從目標行前約 8 秒開始播。
  3. 聽到目標行**開始唱**的瞬間再按 **S**。
  4. 會用新的時間從目標行前 3 秒重播給你確認：準就按 **Enter**；不準按 **S** 重來；**Esc** 放棄、恢復原值。
  - 小幅微調用 **[ / ]**（0.1 秒）或 **Shift+[ / ]**（1 秒）。
  - 校準面板的「**依時長差估計**」會依「影片比歌詞長多少」直接設定，適合 MV 前面多一段劇情的情況。新建立的歌如果影片較長，已經自動這樣設定過（畫面會提示）。
- **越到後面越偏**：通常是影片版本不同（Live、剪輯版、加速版）。按「換影片」挑時長差最小的（標示 ±0–3 秒的），通常是「- Topic」頻道的音源版。
- **歌詞本身內容或時間就不對**：LRCLIB 上的歌詞是網友上傳的。刪除這首歌，重新建立時從候選裡挑另一個版本。
- **沒有同步歌詞**的歌：用「打點同步」自己打一次。

### 翻譯失敗：找不到 claude 指令

錯誤訊息類似「找不到 claude 指令：…」。

1. 在 **WSL 終端機**執行 `claude --version`：
   - 沒有這個指令 → 先安裝 Claude Code 並執行一次 `claude` 登入。
   - 有 → 繼續下一步。
2. 用一鍵啟動（.bat）時，伺服器跑在非互動 shell，**不會讀你的 `~/.bashrc`**，所以用 npm / nvm 裝的 `claude` 可能找不到。在終端機執行：

   ```bash
   which claude
   ```

   把印出的完整路徑寫進 `.env`：

   ```
   CLAUDE_CLI_PATH=/home/<你的帳號>/.nvm/versions/node/v22.x.x/bin/claude
   ```

   重新啟動伺服器即可。
3. 錯誤訊息是「claude CLI 錯誤：…login…」之類 → 在終端機執行 `claude` 重新登入。
4. 不想用訂閱、改用 API key：`.env` 設 `TRANSLATOR_BACKEND=api` 和 `ANTHROPIC_API_KEY=…`。

### 其他

- **某幾行翻譯是空的**：建立時會提示「有 N 行翻譯失敗」。滑鼠移到那行按 ↻ 重翻，或雙擊自己補。
- **影片不能播**：被禁止嵌入（錯誤 101/150）或已刪除（100）時會自動換下一個候選；候選都不行會打開「換影片」，貼上別的 YouTube 網址即可。
- **8765 port 被別的程式占用**：一鍵啟動視窗會顯示「伺服器啟動失敗」（上面有 `address already in use`）。關掉占用的程式，或在 Windows 設定環境變數 `LYRIC_PLAYER_PORT` 換 port。（如果占用的是本程式自己，.bat 會直接開瀏覽器。）
- **Windows 瀏覽器連不到 localhost:8765**：WSL 預設會轉發 localhost；不行的話在 WSL 執行 `hostname -I`，改用印出的 IP（例如 `http://172.x.x.x:8765`，一鍵啟動已用 `--host 0.0.0.0`）。
- **備份 / 搬家**：整個 `library/` 資料夾就是全部的歌（每首一個 JSON），複製走即可。
